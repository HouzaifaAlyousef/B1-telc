# وين مفاتيح الحلول

الملفّات الكبيرة (PDF الكتب) مشالة من الشجرة عن قصد — بتلاقيهن بالتاريخ:

```
git -c core.quotepath=false log --all --diff-filter=A --name-only \
    --pretty=format:"%h" -- '*.pdf'
git show <commit>:'<المسار>' > /tmp/x.pdf
```

★ أوّل كوميت بالقايمة ممكن يكون كوميت **الحذف**، وقتها الملف بيطلع فاضي.
  دوري لورا لحتى `git cat-file -e <rev>:<path>` ينجح.

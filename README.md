# تدريب telc B1

تطبيق بسيط للتدريب على امتحان telc Deutsch B1، مبني من ملف `Doku/B1 Telc.pdf`.

## المميزات
- تقسيم المادة إلى **نماذج** (Modelltests)، وكل نموذج مقسوم حسب **الأقسام**
  (Leseverstehen 1‑3، Sprachbausteine 1‑2، Hörverstehen 1‑3، Schriftlicher Ausdruck).
- **عدّاد وقت** بيبلش لما تضغطي «ابدأ»، وبيسلّم أوتوماتيكياً لما ينتهي الوقت.
- **نتيجة وتصحيح** بعد التسليم: علامتك، والجواب الصح لكل سؤال.
- التقدّم والنتائج بتنحفظ بالمتصفّح.

## التشغيل
التطبيق ملفات ثابتة بدون أي مكتبات. لازم سيرفر محلي (عشان `fetch` للبيانات):

```bash
python3 -m http.server 8000
# وبعدين افتح http://localhost:8000
```

## البنية
```
index.html          الصفحة الوحيدة
assets/style.css    التنسيق
assets/app.js       المحرّك (عرض الأسئلة، المؤقّت، التصحيح)
data/index.json     فهرس النماذج
data/modell-XX.json محتوى كل نموذج
tools/extract.py    استخراج نص الـPDF
```

## صيغة النموذج
كل قسم فيه `format` بيحدّد نوع الأسئلة:

| format      | الاستعمال                                  |
|-------------|--------------------------------------------|
| `matching`  | وصل نص بعنوان / موقف بإعلان (`bank`)        |
| `mc`        | اختيار من متعدد (`options` لكل سؤال)        |
| `wordbank`  | ملء فراغات من قائمة كلمات (`bank`)          |
| `truefalse` | صح / خطأ (Richtig / Falsch)                 |
| `writing`   | تعبير كتابي مع نقاط مطلوبة ونموذج إجابة     |

# تجربة البوت لأوّل مرّة — الترتيب الكامل

الهدف: تبعت `/start` لبوتك وتوصلك رسالة فيها كود ورابط، وتفتح الرابط
وتحطّ الكود ويفتح معك امتحان.

سلسلة كاملة: **البوت → قاعدة البيانات → الكود → الرابط → التطبيق**.
لو حلقة وحدة ناقصة، الرابط بيوصلك بس ما بيفتح — عشان هيك الترتيب مهم.

---

## قبل ما تبلّش — فحص واحد بيقول لك وين واقف

الصق `supabase/health.sql` بـ**SQL Editor** واضغط Run. للقراءة فقط، ما
بيغيّر ولا صفّ، وبيشتغل حتى لو القاعدة فاضية تماماً.

بيطلع جدول من ٧ صفوف، كل ❌ فيه مكتوب جنبه شو تعمل:

```
 ✅ | نسخة السكيما            | عندك 23 · لازم 23
 ✅ | دوال البوت              | 2 من 2 (bot_levels, bot_demo_code)
 ✅ | جدول telegram_users     | 0 مستخدم مسجّل
 ✅ | مستويات البوت رح يعرضها | b1
 ✅ | المحتوى                 | 17 امتحان منشور · 987 سؤال
 ✅ | حساب أدمن               | 1 أدمن
 ✅ | قائمة الانتظار          | مطفيّة (بلا حدّ) — تمام للتجربة
```

شغّله بعد كل خطوة تحت. لمّا الـ٧ يصيروا ✅، القاعدة جاهزة.

## الخطوات

### ١ · القاعدة  — SQL Editor، بتعرفه

**أ.** الصق `supabase/setup.sql` كامل واضغط Run. آمن للإعادة.

**ب.** الصق البذور. الملف الكامل `supabase/seed/b1.sql` كبير والمحرّر
بيتعتّر عليه، فالأسهل الأربع أجزاء وحدة وحدة:

```
supabase/seed/parts/b1-1.sql
supabase/seed/parts/b1-2.sql
supabase/seed/parts/b1-3.sql
supabase/seed/parts/b1-4.sql
```

آمنين للإعادة كمان. بيحطّوا ١٧ نموذج B1.

**ج.** شغّل `supabase/health.sql`. لازم الصفوف الخمسة الأولى ✅.

> ⚠️ **الدرس يلي انلدغنا فيه أكتر من مرّة:** Cloudflare بيعيد النشر خلال
> دقيقة من أي دفعة، بس **القاعدة ما بتحدّث حالها**. بعد أي تغيير على
> `supabase/`، أعد لصق `setup.sql`.

### ٢ · تسجيل الدخول المجهول — لوحة سوپابيس

**Authentication → Sign In / Providers → Allow anonymous sign-ins** ✅

الطالب ما بيعمل حساب: التطبيق بيسجّله مجهول والكود بيربط الاشتراك فيه.
**بلا هالخيار الكود بيفشل عند الطالب** ولا فحص بيمسكها — ما بتنقرا من SQL.

### ٣ · التطبيق على Cloudflare

`APP_URL` لازم يكون رابط شغّال، وإلا الطالب بياخد كود ورابط ميّت.

بلوحة Cloudflare → Workers → `b1-telc` → **Settings → Builds**:

| | |
|---|---|
| Branch | **`kiko-branch`** ← بند مفتوح، تأكّد منه |
| Build command | `./tools/build_dist.sh` |
| Deploy command | `npx wrangler deploy` |
| Root directory | `/` |

افتح `https://b1-telc.b1-telc.workers.dev` بمتصفّحك. لازم تشوف صفحة
إدخال الكود. لو ما فتحت، وقّف هون — الباقي ما بيفيد.

### ٤ · نشر الدالة  — هون بس بدّك تيرمينال

هي الخطوة الوحيدة يلي مو بالمتصفّح. **طريقتين:**

#### الطريقة أ — لوحة سوپابيس (بلا تيرمينال) ✅ الأسهل

سوپابيس → **Edge Functions** → **Deploy a new function** → **Via Editor**

- الاسم: `telegram`
- الصق محتوى `supabase/functions/telegram/index.ts` كامل (٢٥٤ سطر)
- **شيلة علامة «Verify JWT»** — تلغرام ما بيبعت JWT، والحماية بالترويسة
  السرّية. لو تركتها مفعّلة البوت بيضل ساكت
- Deploy

#### الطريقة ب — تيرمينال

```bash
npx supabase login
npx supabase link --project-ref ejwzvgabqoevhaimbvik
npx supabase functions deploy telegram --no-verify-jwt
```

### ٥ · البوت والأسرار

**أ. اعمل البوت:** بتلغرام، احكي مع [@BotFather](https://t.me/BotFather)
واكتب `/newbot`. بيعطيك توكن شكله `8123456789:AAH…`

> 🔴 **التوكن كلمة سرّ.** ما بينحطّ بملف ولا بغيت ولا بشات — لا معي ولا
> مع غيري. اكتبه مباشرةً بخانة الأسرار بلوحة سوپابيس.

**ب. اعمل سرّ للـwebhook:** أي نصّ عشوائي طويل. لو ما عندك أمر يولّده،
اكتب ٣٠+ حرف ورقم عشوائي من راسك. **احفظه — بدّك ياه مرّتين.**

**ج. حطّهن:** سوپابيس → **Edge Functions → Secrets** → Add:

| الاسم | القيمة |
|---|---|
| `TELEGRAM_BOT_TOKEN` | التوكن من BotFather |
| `TELEGRAM_WEBHOOK_SECRET` | النصّ العشوائي |
| `APP_URL` | `https://b1-telc.b1-telc.workers.dev` |

`SUPABASE_URL` و`SUPABASE_SERVICE_ROLE_KEY` بتتحطّوا لحالهن — **لا تحطّهن**.

### ٦ · وصّل تلغرام بالدالة

افتح هالرابط بالمتصفّح بعد ما تبدّل القيمتين — مو لازم تيرمينال:

```
https://api.telegram.org/bot<التوكن>/setWebhook?url=https://ejwzvgabqoevhaimbvik.supabase.co/functions/v1/telegram&secret_token=<السرّ>&allowed_updates=["message","callback_query"]
```

لازم يرجّعلك `{"ok":true,...}`.

**للتأكّد:**
```
https://api.telegram.org/bot<التوكن>/getWebhookInfo
```
`pending_update_count` لازم يكون `0` وما يكون في `last_error_message`.

### ٧ · جرّب

ابعت `/start` لبوتك. لازم تشوف أربع أزرار لغات ← نوع الامتحان ←
المستوى ← كود ورابط.

بعدها افتح الرابط، حطّ الكود، ولازم يفتح معك امتحان B1 لمدّة ٢٤ ساعة.

## لمّا ما يشتغل

| العارض | السبب |
|---|---|
| البوت ساكت، و`getWebhookInfo` بيقول **403** | `TELEGRAM_WEBHOOK_SECRET` مختلف عن `secret_token` يلي بعتّه |
| البوت ساكت، وما في خطأ بتلغرام | الرابط غلط، أو نشرتها و«Verify JWT» مفعّلة |
| «ما في امتحانات متاحة» | صفّ ٤ بالفحص ❌ — ما في مستوى منشور فيه امتحان منشور |
| «صار خطأ» على كل مستوى | القاعدة متأخّرة — أعد لصق `setup.sql` |
| الكود بيقول «انتظار» بدل ما يفوت | صفّ ٧ بالفحص ⚠️ — قائمة الانتظار مليانة. صفر = بلا حدّ |
| الرابط بيفتح صفحة بيضا | Cloudflare ناشر من فرع تاني، أو البناء فشل |
| الكود مرفوض عند الطالب | تسجيل الدخول المجهول مطفي (خطوة ٢) |

## شو ما إله دخل بهالتجربة

- **`correct-writing`** — للتصحيح الآلي للكتابة. ما بتحتاجها لتجربة
  البوت؛ الطالب بيقدر يحلّ كل شي ما عدا تصحيح التعبير الكتابي.
- **الصور والصوت** — Hörverstehen ما بيشتغل بلا صوت، والقراءة الثالثة
  بدها صورة. الأقسام التانية بتشتغل عادي.
- **B2** — لسا ما انستورد. البوت رح يعرض B1 بس.
